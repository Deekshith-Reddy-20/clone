# Outpero Voice Agent Integration (Karyuk)

Outpero is used as the **backend voice-agent infrastructure**. Karyuk remains the only dashboard for registering agents, placing test calls, monitoring calls, and viewing synchronized leads.

## Architecture

```
Karyuk Dashboard → Karyuk API → Outpero Lead Intake API → Voice Agent Call
                                         ↓
                              Post-call webhook (call.ended)
                                         ↓
                              Karyuk webhook handler (HMAC verified)
                                         ↓
                              Calls + Leads tables → Dashboard
```

All Outpero credentials stay on the server. The browser never receives lead secrets.

## Official Outpero endpoints used

| Method | Endpoint | Purpose |
|--------|----------|---------|
| `POST` | `/lead-intake/{slug}` | Submit a lead / start an outbound call |
| `GET` | `/lead-intake/{slug}/schema` | Fetch expected pre-call fields |
| `GET` | `/lead-intake/{slug}/calls/{call_id}` | Poll call status |
| Incoming | Post-call webhook `call.ended` | Transcript, summary, captured fields, recording |

Base URL default: `https://api.outpero.com`

## Supported vs unsupported

**Supported (official)**

- Submit lead → agent calls (with pre-call variables / prior context)
- Fetch schema
- Poll call by ID
- Receive signed post-call webhooks
- Mid-call Custom API Action → Karyuk lead-context endpoint

**Not available via Outpero public API**

- List agents remotely (register each AI employee locally with slug + secret)
- Update agent prompts/settings via API
- Activate/deactivate inside Outpero via API (Karyuk can mark local status only)
- Browser-based voice testing
- Full remote call-history listing
- Webhook retries from Outpero (we return 200 fast + poll/reconcile by call ID)

## Environment variables

```bash
OUTPERO_API_BASE_URL=https://api.outpero.com
OUTPERO_WEBHOOK_MAX_AGE_SECONDS=300
OUTPERO_WEBHOOK_SHARED_SECRET=   # optional fallback HMAC secret
PUBLIC_API_BASE_URL=https://your-public-host   # required for webhook URL shown in UI
```

Per-agent secrets (from Outpero Instant Leads / Post-Call tabs) are stored in `outpero_agents`:

- `slug`
- `lead_secret` (`X-Outpero-Lead-Secret`)
- `webhook_signing_secret` (HMAC)

There is **no global Outpero API key** in the official docs.

## Connect Outpero

1. In Outpero, open the AI employee → **Instant leads** → copy **slug** and **lead secret**.
2. In Karyuk go to **`/app/voice-agents`** → Register agent (name, slug, lead secret).
3. In Outpero → **Post-Call → Webhooks**, add:
   - URL: `{PUBLIC_API_BASE_URL}/v1/webhooks/outpero/{workspace_id}`
   - Trigger: Every call (recommended)
   - Enable signing; paste the same signing secret into the Karyuk agent form
   - Optional header: `X-Outpero-Agent-Slug: {slug}`
4. (Optional) Custom API Action during call:
   - URL: `{PUBLIC_API_BASE_URL}/v1/webhooks/outpero/{workspace_id}/lead-context`
   - Header: `X-Outpero-Action-Secret: {action_secret from agent detail}`
   - Body JSON: `{ "phone": "{{phone}}" }` (or the field Outpero collected)

## Test a voice agent

1. Open `/app/voice-agents`
2. Select the agent
3. Enter an Indian mobile number
4. Check the confirmation box
5. Click **Start test call**
6. Wait for webhook / status poll to fill transcript, summary, recording, captured fields

## Verify generated leads

1. After `call.ended`, open `/app/voice-agents` → **Leads generated by voice agents**
2. Confirm the lead also appears under `/app/leads` with `source: outpero`
3. Open `/app/conversations/{callId}` for transcript / recording / captured fields
4. Call again with the same phone — lead is updated, not duplicated (`uq_lead_phone`)

## Karyuk API surface

- `GET  /v1/workspaces/{id}/outpero/status`

- `PATCH /v1/workspaces/{id}/outpero/agents/{agent_id}`
- `POST /v1/workspaces/{id}/outpero/agents/{agent_id}/refresh-schema`

- `POST /v1/workspaces/{id}/outpero/agents/{agent_id}/calls`
- `GET  /v1/workspaces/{id}/outpero/calls`
- `POST /v1/workspaces/{id}/outpero/calls/{call_id}/refresh`
- `GET  /v1/workspaces/{id}/outpero/leads`
- `GET  /v1/workspaces/{id}/outpero/leads/{lead_id}/history`
- `POST /v1/webhooks/outpero/{workspace_id}`
- `POST /v1/webhooks/outpero/{workspace_id}/lead-context`
